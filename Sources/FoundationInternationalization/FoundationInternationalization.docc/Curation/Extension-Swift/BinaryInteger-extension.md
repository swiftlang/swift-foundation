# ``FoundationInternationalization/Swift/BinaryInteger``

Methods that extend the Swift binary integer protocol.

## Overview

Foundation adds support for formatting an integer with a `FormatStyle` and for creating an integer by parsing with a `FormatStyle` or a `ParseStrategy`.

## Topics

### Creating an integer by parsing

- ``BinaryInteger/init(_:format:lenient:)-58fr9``
- ``BinaryInteger/init(_:strategy:)-3hx3x``
- ``BinaryInteger/init(_:format:lenient:)-24fkf`` 
- ``BinaryInteger/init(_:format:lenient:)-2xo3o`` 

### Formatting an integer

- ``BinaryInteger/formatted()``
- ``BinaryInteger/formatted(_:)-6ss2f``
- ``BinaryInteger/formatted(_:)-9xek5``

### Supporting types

- ``IntegerFormatStyle``
- ``IntegerParseStrategy``
