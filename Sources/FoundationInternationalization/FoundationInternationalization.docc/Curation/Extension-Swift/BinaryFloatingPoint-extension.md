# ``FoundationInternationalization/Swift/BinaryFloatingPoint``

Methods and properties that extend the Swift binary floating-point protocol.

## Overview

Foundation adds support for formatting a floating-point value with a `FormatStyle` and for creating a floating-point value by parsing with a `FormatStyle` or a `ParseStrategy`.



## Topics

### Creating an floating-point value by parsing

- ``BinaryFloatingPoint/init(_:format:lenient:)-72i7z`` 
- ``BinaryFloatingPoint/init(_:strategy:)-4l0ts``
- ``BinaryFloatingPoint/init(_:format:lenient:)-3paim`` 
- ``BinaryFloatingPoint/init(_:format:lenient:)-5uoat`` 

### Formatting a floating-point value

- ``BinaryFloatingPoint/formatted()``
- ``BinaryFloatingPoint/formatted(_:)-1v618``
- ``BinaryFloatingPoint/formatted(_:)-5eueh``

### Supporting types

- ``FloatingPointFormatStyle``
- ``FloatingPointParseStrategy``
