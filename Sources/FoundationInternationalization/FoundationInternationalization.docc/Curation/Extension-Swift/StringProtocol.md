# ``FoundationInternationalization/Swift/StringProtocol``

Methods and properties that extend the Swift string protocol.


## Overview

FoundationInternationalization extends the Swift string protocol by adding support for localized capitalization.

## Topics

### Applying capitalization

- ``localizedCapitalized``
- ``capitalized(with:)``

### Lower casing

- ``localizedLowercase``
- ``lowercased(with:)``


### Upper casing

- ``localizedUppercase``
- ``uppercased(with:)``
