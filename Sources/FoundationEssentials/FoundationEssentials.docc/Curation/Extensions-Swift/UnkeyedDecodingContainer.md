# ``Swift/UnkeyedDecodingContainer``

Methods that extend Swift unkeyed decoding.

## Overview

Foundation adds support for decoding with a configuration object, as defined in the ``DecodableWithConfiguration`` and ``CodableWithConfiguration`` protocols.

## Topics

### Decoding

- ``decode(_:configuration:)-(_,T.DecodingConfiguration)``
- ``decode(_:configuration:)-(_,C.Type)``
- ``decodeIfPresent(_:configuration:)-(_,T.DecodingConfiguration)``
- ``decodeIfPresent(_:configuration:)-(_,C.Type)``
