# ``Swift/Range``

Methods that extend the Swift range type.

## Overview

Foundation adds support for creating ranges from ``AttributedString`` instances, and for validating whether a given range is valid for use with a given attributed string or attributed substring.

## Topics

### Creating a range from an attributed string

- ``init(_:in:)-8bs53``
- ``init(_:in:)-9n60y``

### Testing validity of a range with an attributed string

- ``isValid(within:)-(AttributedStringProtocol)``
- ``isValid(within:)-(DiscontiguousAttributedSubstring)``
