# ``Swift/KeyedEncodingContainer``

Methods that extend Swift keyed encoding.

## Overview

Foundation adds support for encoding with a configuration object, as defined in the ``EncodableWithConfiguration`` and ``CodableWithConfiguration`` protocols.
